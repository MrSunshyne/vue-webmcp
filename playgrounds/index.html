vue-webmcp playgrounds

The same todo demo built two ways. Both register WebMCP tools on document.modelContext; the toolset changes as you mount and unmount parts of the UI.

  • Vite + Vue — uses vue-webmcp directly
  • Nuxt — uses the nuxt-webmcp module

WebMCP is in Chrome origin trial. To see the tools register, use Chrome 149+ with chrome://flags/#enable-webmcp-testing enabled, and invoke them with the Model Context Tool Inspector extension. In any other browser the demos fall back to a notice — that fallback is part of the demo.
