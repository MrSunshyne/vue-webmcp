vue-webmcp playgrounds

The same todo demo, built with Vite and with Nuxt. Both register WebMCP tools on document.modelContext. Mounting and unmounting parts of the UI registers and unregisters tools.

  • Vite, importing vue-webmcp directly
  • Nuxt, using the nuxt-webmcp module

WebMCP is in Chrome origin trial. Tools register in Chrome 149+ with chrome://flags/#enable-webmcp-testing enabled, and can be invoked with the Model Context Tool Inspector extension. Other browsers show a fallback notice.
